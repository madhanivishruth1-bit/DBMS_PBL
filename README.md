# Sports Club Hub

DESIGN AND IMPLEMENTATION OF A DATABASE MANAGEMENT SYSTEM FOR SPORTS CLUB MEMBERSHIP AND TOURNAMENT MANAGEMENT SYSTEM

Description:

This project involves the design and development of a relational database management system for a Sports Club Membership and Tournament Management System. Sports clubs need member, team, coach, facility, training, fixture, result, fee and equipment records. Manual coordination makes scheduling difficult. Students will analyse the requirements and identify the major entities, attributes, relationships and user roles. The conceptual design should represent members, sports, teams, coaches, facilities, training sessions, tournaments, fixtures, participants, results, membership plans, payments and equipment issues. The ER model must be converted into a relational schema and normalized up to Third Normal Form (3NF). The database may be implemented using MySQL, PostgreSQL or Oracle with suitable primary keys, foreign keys, UNIQUE, NOT NULL, CHECK and DEFAULT constraints. Important business rules include no overlapping facility or team schedule, active membership required, valid scores, capacity limits and equipment-return limits. Students should populate the tables with realistic sample data and prepare SQL statements for data retrieval, joins, aggregate functions, nested queries, views and meaningful reports such as memberships, fixtures, standings, facility use, player performance, fee dues and equipment status. A small front-end application developed using Java or Python should support membership, team formation, training scheduling, facility booking, fixture creation, result entry, fee collection and reporting.
